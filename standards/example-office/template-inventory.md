# Template inventory (example)

Measured from the office template by opening it and reading it with VibeModel (`template`), not typed over from the manual. Re-measure after every template update.

## Phases and phase filters
Phases: `1. Existing`, `2. New construction`, `3. Final`.
Filters: `1.1 Existing`, `2.1 Demolished projected on existing incl. temporary`, `2.3 New projected on existing incl. temporary`, `2.7 New only`, `3.1 Final`, `Show All`.
Pitfall: most work views in the template sit on phase `1. Existing` — elements created there by hand become existing.

## View templates
`EX_W_C_Plan`, `EX_W_C_3D`, `EX_W_C_Sections`, `EX_P_C_Plan`, `EX_P_C_3D`, `EX_P_C_Sections`.
