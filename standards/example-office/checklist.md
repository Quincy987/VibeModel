# Model delivery checklist (example)

- A File name follows `<digit>_<part>.rvt` → check `file-name`
- B1 Level of detail agreed up front → manual
- B4 Survey point at 0,0,0 → check `survey-point-origin`
- B5 Project base point pinned → check `base-point-pinned`
- B6 Underlays and grids pinned → check `pinned`
- B7 Phasing applied (no element without a phase, tables 1 and 2) → checks `phase-not-none`, `phase-filter-digit`
- B10 Families from the template or the office library → check `family-source`
- D1 Plot views keep their view template → check `view-template-required`
- D2 Underlays linked, not imported → check `links-are-links`
- E1 Object code filled on new work → check `param-filled`
