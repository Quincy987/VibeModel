# Families and library

1. Already in the model (`familytypes`)? Use it.
2. Otherwise from the office library (`library <term>`, then `loadfamily`).
3. Otherwise a project family from the office family templates, saved in `...\Model\Project families\`.

Prefixes: `EX_` office, `NLRS_` Dutch Revit Standards library, `GM_` generic model (only when no real category fits).
