# Coordinates and underlays

- Survey point = national grid origin (0,0,0); never move it.
- Link the base map: Link CAD, off-axis correction off, orient to view off. First file: centre-to-centre, then move it into place (never rotate) and acquire its shared coordinates.
- Round the project base point N/S and E/W to whole metres and pin it.
- Later underlays: Auto – By Shared Coordinates, then pin. Never start from a DGN.
