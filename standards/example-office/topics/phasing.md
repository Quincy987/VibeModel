# Phasing

## Table 1 — phases per element (created / demolished)
- Existing, stays: `1. Existing` / None
- Existing, demolished in the project: `1. Existing` / `2. New construction`
- Temporary works: `2. New construction` / `2. New construction`
- New: `2. New construction` / None
- Built later by a related project: `3. Final` / None

## Table 2 — phase filter × phase on a view
Rule: the phase filter and the phase start with the same digit.
- `1.1 Existing` + `1. Existing`
- `2.1` … `2.7` + `2. New construction`
- `3.1 Final` + `3. Final`
